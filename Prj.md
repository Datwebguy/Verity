# Verity — Project

## Name
Verity

## One-line description
An autonomous agent that produces public, graded practice decisions from live RYO-CHAN research tools.

## Tracks
- Autonomous Agents (primary)
- New Skills (secondary)

## Hackathon
- Event: RYO-CHAN Hackathon 2026
- Official page: https://ryobuild.com/hackathon
- Deadline: 11 November 2026, 23:59 JST
- Submission requirements: private GitHub repository, .env.example (no real keys), demo video
- Constraint: practice decisions only, no real order placement

## Goal
Ship a working agent that:
1. Calls multiple RYO-CHAN tools
2. Writes a structured practice receipt
3. Grades the receipt against later price movement
4. Publishes the receipt and grade publicly
5. Exposes the same logic as a callable skill

## Repository rules for any agent working here
- Read every markdown file in this repository before writing code.
- Build the full product described in the markdown files.
- Do not use Claude as an author or co-author in any file, commit, comment, or generated text.
- Do not call Claude APIs.
- Do not commit real API keys.
- Do not invent RYO data.
- Do not place real trades.
- Make tool failures visible.
- Prefer complete working loops over partial features.
